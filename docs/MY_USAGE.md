# My Usage

The **My Usage** page gives you a personal, cross-observatory view of everything you've captured — how many observations and files you've accumulated, how much storage they occupy, and how much telescope time they represent — with tools to drill in and download in bulk.

Open it from **My Usage** in the main navigation menu. It is available to every user.

## Overview

My Usage summarises *your own* files, grouped the way you choose. Four summary cards at the top show the totals for whatever is currently in view (or selected):

| Card | Shows |
|------|-------|
| **Observations** | Number of observations the files belong to |
| **Files** | Total number of files |
| **Storage** | Total size on disk (GB) |
| **Exposure Time** | Total integration time (hours) |

When nothing is selected, the cards total the whole current grouping. As soon as you tick one or more groups or individual files, the cards switch to totalling just your selection — a quick way to size up "how much is this target costing me" before downloading.

## Grouping Your Data

Tabs across the top let you break your data down four ways:

| Tab | Groups your files by |
|-----|----------------------|
| **By Observatory** | The observatory that captured them |
| **By Project** | The project they belong to |
| **By Target** | The astronomical target |
| **By Date** | The capture date |

Each row is one group (one observatory, project, target, or date) with its observation count, file count, size, and exposure time. Click a row to **expand** it and list the individual files inside.

## Time Range

A time-range selector limits the view to recently captured data; the default is the **last 30 days**. On the **By Date** tab you can instead pick an explicit **From** and **To** date range for precise windows (for example, a single observing run or a specific month).

## Selecting and Downloading

My Usage doubles as a bulk-download tool:

- **Select a whole group** — tick a group's checkbox to include every file in it.
- **Select individual files** — expand a group and tick specific files. (Selecting individual files clears that group's whole-group checkbox, so the two levels don't double-count.)
- **Select all** — the header checkbox selects or clears every group in the current tab.

With a selection made, use the download action to retrieve everything you've selected. The summary cards show exactly what the download will contain before you start.

!!! tip "Pop-out window"
    From the account (avatar) menu you can open **My Usage** in its own floating window. It opens in a compact layout sized to sit alongside your other views — handy for keeping an eye on storage while you work elsewhere in the app.
